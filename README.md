# English Quest 111–114

A mobile-friendly, offline-capable static English practice page.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **public** repository (for example `english-quest`).
2. Upload `index.html` from this folder (or upload the ZIP contents).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish. Your site URL will look like `https://YOUR-USERNAME.github.io/english-quest/`.

The page includes the four multiple-choice tests, rewrite practice with answer hints, original text memes, 3D-style UI, and a synthesized music loop. Audio starts only after the user taps the sound button because browsers block autoplay.
